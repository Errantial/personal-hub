## Implemented local review cadence policy (2026-10-11)

Responsibility local daily/weekly scheduling uses Temporal compatible disambiguation: shift a missing time forward by the gap and choose the earlier repeated time. Missed civil slots coalesce into one explicit blocked review admission. This is an implementation policy for review schedules, not a change to Calendar input or permission to execute agents. Monthly/cron/multiple-weekday rules and background scheduling remain pending. See [local schedules](responsibility-local-schedules.md).
