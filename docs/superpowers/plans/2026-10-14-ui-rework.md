# UI rework (Today, Assistant, Calendar) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework the Today, Assistant and Calendar screens for readability, as specified, in three PRs.

**Architecture:** Front end only (`apps/web`). Pure layout and merge logic goes into small `lib/` modules with unit tests (Vitest). Components consume them; Playwright e2e tests cover the screens. No API, contract or migration changes.

**Tech Stack:** React 19 + Vite, TypeScript, Temporal (`@hub/contracts` re-export), Vitest, Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-10-14-ui-rework-design.md`

## Global Constraints

- No server, contract or migration changes; use existing endpoints and schemas only.
- WCAG 2.2 AA; targets ≥ 44 px standard and ≥ 48 px e-ink; no horizontal overflow at 320 px.
- Colors only through tokens in `styles/tokens.css`, each with light, dark (`[data-scheme='dark']`) and e-ink values; block text ≥ 4.5:1 and blocks ≥ 3:1.
- Interface copy: concise labels; secondary explanation goes in `Help`. Errors, offline and conflict states stay visible.
- Offline: Today reads keep using `getSnapshot`. Add task keeps queueing through `useMutation`.
- Every PR updates `docs/ui-agent-ledger.md` and passes `npm run check` and `npm run test:e2e`.
- Branches: `ui/today-rework`, `ui/assistant-rework`, `ui/calendar-rework`, each from `main` after the previous merges.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A timed event crossing midnight or a daylight-saving day.** It must be clipped to the visible day (23/25-hour days included), with no block outside the grid. Test in Task 7.
2. **Four or more overlapping events.** Each must stay clickable with a readable title, in equal-width columns. Test in Task 7.
3. **Long titles at 320 px in Today rows, chat bubbles and month chips.** They must wrap or ellipsize with no overflow. Covered by the accessibility sweeps in Tasks 3, 5 and 11.
4. **Calendar viewing time zone ≠ device time zone.** Grid positions and the "now" line must use the viewing zone. Test in Task 7, plus the now line in Task 9.
5. **Today with one source failed and the others loaded.** The merged list must still show loaded items, with that source's retry message. Test in Task 3.

  export type GridSource = 'event' | 'study' | 'canvas' | 'task';
  export type Block = {
    key: string;
    source: GridSource;
    title: string;

  - `dayLength is 1380 on the US spring-forward day` (2026-03-08, America/Denver).
